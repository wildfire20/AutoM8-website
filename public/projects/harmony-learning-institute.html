Project overview

One connected admissions journey.

AutoM8 redesigned and expanded Harmony Learning Institute’s digital platform into a modern public school website connected to a secure school-management and admissions system. The platform supports the journey from a parent discovering the school and submitting an application through document collection, admissions review, registration and ongoing school communication, while providing administrators with tools to manage the process from one central environment.

Online admissions

From application to registration.

Parents can submit learner applications online and receive a unique reference number in a format such as HLI-2027-XXXX.

04

Admissions communication

Timely updates without manual chasing.

The platform supports structured communication at important points in the admissions process.

Parent communication

  • Application received confirmation
  • Under-review updates
  • More-information-required requests
  • Approval and registration updates
  • Not-accepted or waitlist communication

Administrator notifications

  • New application
  • New or replacement document uploaded
  • Requested information submitted
  • Bring in Person selected
  • Registration submitted

Notifications can take administrators directly to the relevant application.

Secure parent workflows

Request only what is missing.

Administrators can request specific information or documents without exposing the wider application or private school systems.

Private information requests

  • Administrator selects the information required
  • Parent receives a private secure link
  • Access is limited to the relevant application
  • Save-and-return where applicable
  • Expiring links can be revoked and reissued

Document management

  • Upload Online or Bring in Person
  • PDF, JPG and PNG validation
  • Private document storage
  • Received, Pending Review and Replacement Required statuses
  • Replacement reasons, secure resubmission and admin notification
This case study does not display learner records, submitted documents, private administrator URLs or authentication details.
